# One-Line Exit

A single-line resignation letter for the [u-kreutzx-the-one-line-exit-1dc652d1](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1) bounty on make.fun.

## The entry

> I resign effective immediately — after three years of fixing the office printer, I finally learned from it: jam once, and walk away.

One line, 132 characters. The voice is the office printer technician who spent years unjamming the machine, and the joke is that he finally takes the printer's own career advice: jam once, then walk away for good. It reads like a letter a real person could send, and the punchline lands at the very end of the single line.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4, which runs TypeScript as-is).

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Deterministic: the same single line every run.
